# 01-05---Plano de Continuidade de Negócios

Este repositório contém um trabalho acadêmico desenvolvido para a disciplina **Sistemas Computacionais e Segurança (SCS)** do curso de graduação da **Universidade São Judas Tadeu (USJT)**, sob orientação do professor **Calvetti**.

## 📄 Descrição

O projeto consiste na elaboração de um **Plano de Continuidade de Negócios (Business Continuity Plan – BCP)** para uma empresa fictícia chamada **Language Masters**, uma escola de idiomas com operações presenciais e online.

O objetivo do trabalho é aplicar os conhecimentos adquiridos em sala de aula sobre gestão de riscos, análise de impacto nos negócios e estratégias de continuidade operacional.

## 📚 Estrutura do Documento

O plano contempla os seguintes tópicos:

1. Introdução da empresa e seu cenário
2. Recursos críticos identificados
3. Análise de Impacto nos Negócios (BIA)
4. Estratégias de recuperação propostas
5. Plano de ação detalhado
6. Sugestão de teste do plano
7. Conclusão
